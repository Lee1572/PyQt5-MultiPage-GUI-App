# Multi-Page GUI Desktop Application with PyQt5

A secure, professional desktop application built with Python and PyQt5 featuring a multi-page interface with user authentication, real-time updates, and interactive components.

## ✨ Features

- **Secure Login System**: Username/password authentication with validation
- **Multi-Page Navigation**: Seamless transition between application sections
- **Real-Time Clock**: Live updating time display on user profile page
- **Interactive Calendar**: Functional calendar with date selection capabilities
- **Professional UI**: Clean, responsive interface built with Qt Designer
- **Modular Architecture**: Well-organized codebase for easy maintenance

## 🏗️ Project Structure

PyQt5-MultiPage-GUI-App/
├── src/
│ ├── main.py # Application entry point
│ ├── login_window.py # Login authentication system
│ ├── main_window.py # Main dashboard navigation
│ ├── user_info_window.py # User profile with live clock
│ └── calendar_window.py # Interactive calendar interface
├── ui/
│ ├── login.ui # Login interface design
│ ├── main_menu.ui # Main menu design
│ ├── user_info.ui # User profile design
│ └── calendar.ui # Calendar interface design
├── assets/
│ └── logo.png # Application logo
├── requirements.txt # Python dependencies
└── README.md # Project documentation
